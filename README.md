# موقع OL ELLABIB — دليل التعديل السريع

## 🚀 أول مرة
1. **دبل كليك على `download-stitch-images.bat`** ← بينزّل صور تصميم Stitch في `assets/images`.
2. **افتح `index.html`** في المتصفح (دبل كليك) وتلاقي الموقع شغال.
   - في VS Code: نزّل إضافة **Live Server** ← كليك يمين على `index.html` ← **Open with Live Server**، والصفحة هتتحدث لوحدها مع كل حفظ.

## 📁 الملفات
```
ol clinic/
├── index.html            ← هيكل الصفحة (مش محتاج تلمسه غالبًا)
├── clinic-config.js      ← ⭐ كل الكلام والصور والأرقام هنا
├── css/style.css         ← الألوان (الغامق والفاتح في أول الملف) والتصميم
├── js/main.js            ← التشغيل (اللغة، الوضع، القائمة، الحجز...)
├── assets/images/        ← الصور (team/ للفريق، logos/ للوجوهات)
├── images-sheet.csv      ← 📋 شيت بكل أماكن الصور في الموقع
└── download-stitch-images.bat
```

## ✏️ إزاي أغيّر…

| عاوز تغيّر | فين |
|---|---|
| أي كلام عربي أو إنجليزي | `clinic-config.js` ← دوّر على الكلام (Ctrl+F) وعدّل `en` أو `ar` |
| صورة | حط الصورة الجديدة في `assets/images` بنفس الاسم القديم **أو** اكتب اسمها الجديد في `clinic-config.js` |
| التليفون / الواتساب / الإيميل / العنوان | `clinic-config.js` ← جزء `clinic` |
| مواعيد العمل | `clinic-config.js` ← `clinic.hours` |
| إضافة خدمة / عضو في الفريق / صورة معرض / رأي | انسخ بلوك `{ ... },` كامل في نفس القائمة والصقه تحته وعدّل فيه |
| فريقنا (الشريط اللي بيلف) | `clinic-config.js` ← `doctors` (الأسماء والصور والشارة، و`speed` للسرعة) |
| صور العيادة (جولة في العيادة) | حط الصور في `assets/images/clinic/` بأسماء `clinic-1.jpg` و`clinic-2.jpg`... وهتظهر لوحدها ← أسماء الأماكن في `clinic-config.js` ← `tour` |
| لوجو الهيدر | `clinic-config.js` ← `clinic.logo` (نسخة للغامق ونسخة للفاتح) |
| لوجوهات العيادات في البنر | `clinic-config.js` ← `clinic.brands` |
| لون | `css/style.css` ← أول جزء (🌙 غامق) أو تاني جزء (☀️ فاتح) |
| الوضع أو اللغة اللي الموقع بيفتح بيها | `clinic-config.js` ← `settings` (الافتراضي: غامق + إنجليزي) |

> ⚠️ لو الموقع فتح فاضي بعد تعديل: غالبًا فيه فاصلة `,` أو علامة تنصيص `"` اتمسحت في `clinic-config.js`. اضغط F12 في المتصفح ← Console وهتلاقي رسالة بتقولك.

## 🖼️ إضافة الصور
**كل مكان صورة في الموقع متسجل في `images-sheet.csv`** (افتحه بـ Excel): القسم، اسم الملف، مكانه في الكونفج، المقاس، وهل الصورة موجودة ولا لأ.

1. **جهّز الصورة بالمقاس اللي في الشيت.** صوّر طولي للفريق وعرضي للبنر والمعرض.
2. **صغّر حجمها** على [squoosh.app](https://squoosh.app): اختار **MozJPEG** بجودة 75–80، وخلي الصورة أقل من 300KB (والبنر أقل من 500KB). ده أهم حاجة لسرعة الموقع.
3. **سمّيها بالإنجليزي بحروف صغيرة ومن غير مسافات**، زي `omnia-ellabib.jpg`. الأسماء العربي والمسافات بتعمل مشاكل على الاستضافة.
4. **سمّيها بالاسم اللي في الشيت بالظبط وحطها في نفس الفولدر**:
   صور العيادة في `assets/images/clinic/` (clinic-1.jpg، clinic-2.jpg...)، وصور الفريق في `assets/images/team/`، والباقي في `assets/images/`.
   **كده خلاص** ← اعمل Refresh والصورة هتظهر لوحدها مكان الخلفية الذهبية، من غير ما تعدّل أي كود.
5. **لو عاوز تزوّد صورة جديدة** (صورة سابعة للعيادة مثلًا): سمّيها `clinic-7.jpg` وانسخ آخر سطر في `tour.items` في `clinic-config.js` والصقه تحته وغيّر الرقم واسم المكان:
   ```js
   { image: "assets/images/clinic/clinic-7.jpg", caption: { en: "Consultation Room", ar: "غرفة الاستشارة" } },
   ```
6. **حدّث الشيت**: غيّر الحالة لـ "موجودة ✅".

> 💡 الصور اللي لسه متحطتش بيظهر مكانها خلفية ذهبية بعلامة اللوجو، فالموقع بيفضل شكله كامل حتى قبل ما الصور تكمل.

## 📅 تفعيل الحجز الأونلاين (Google Meet)
1. افتح **Google Calendar** بحساب العيادة ← **Create** ← **Appointment schedule**.
2. حدد المواعيد ومدة الاستشارة (٢٠ دقيقة مثلًا)، وفي **Location** اختار **Google Meet video conference**.
3. في **Booking form** ضيف سؤال "رقم الواتساب" وسؤال "التخصص (أسنان / جلدية)".
4. احفظ ← **Share** ← انسخ لينك **Booking page**.
5. الصقه في `clinic-config.js` ← `booking.googleCalendarUrl`.

جوجل بعدها بيعمل لينك الـ Meet ويبعت إيميل التأكيد للعميل والعيادة لوحده.
لحد ما تحط اللينك، تاب الأونلاين بيعرض زرار "احجز على الواتساب".

**زيارة العيادة:** الفورم بيفتح واتساب العيادة برسالة جاهزة فيها بيانات المريض. مفيش سيرفر ولا قاعدة بيانات محتاجة.

- **التحديث أوتوماتيك:** أي تعديل يعمله Claude بيترفع لوحده في آخر كل رد، واللينك بيتحدث خلال دقيقة أو اتنين.

- اللي حصل في كل رفعة بيتكتب في `tools/publish.log` (على الجهاز بس).
